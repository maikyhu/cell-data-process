# IL-6数据可视化项目

## 项目概述

本项目用于绘制IL-6（白细胞介素-6）实验数据的可视化图表，包括柱状图和曲线图，展示不同浓度下四种分子（a, b, c, d）对IL-6水平的影响及其相对抑制效果。

## 项目目标

1. **柱状图**：展示不同浓度（0-32μM）下IL-6的绝对水平（pg/mL）
2. **曲线图**：展示四种分子（a, b, c, d）在不同浓度下的相对抑制效果（%）

## 功能模块

### 1. 数据处理模块
- 组织和整理原始实验数据
- 包含IL-6水平数据和相对抑制百分比数据
- 包含误差数据（error bars）

### 2. 柱状图生成模块
- **功能**：绘制IL-6水平随浓度变化的柱状图
- **特点**：
  - 横坐标：浓度（0, 2, 4, 8, 16, 32 μM）
  - 纵坐标：IL-6水平（pg/mL）
  - 0μM浓度仅显示LPS对照组
  - 其他浓度显示a, b, c, d四组数据
  - 包含误差棒（error bars）
  - 使用指定配色方案

### 3. 曲线图生成模块
- **功能**：绘制相对抑制效果随浓度变化的曲线图
- **特点**：
  - 横坐标：浓度（2, 4, 8, 16, 32 μM）
  - 纵坐标：相对抑制效果（%）
  - 四条曲线分别代表分子a, b, c, d
  - 包含误差棒
  - 使用指定配色方案

## 技术栈

### 编程语言
- Python 3.12

### 依赖库
- **matplotlib (3.10.7)**: 数据可视化核心库
- **numpy (2.3.5)**: 数值计算和数据处理

### 配色方案
项目使用以下颜色代码：
- `#E89DA0` - LPS组（粉红色）
- `#88CEE6` - 分子a组（天蓝色）
- `#F6C8A8` - 分子b组（浅橙色）
- `#B2D3A4` - 分子c组（浅绿色）
- `#9FBA95` - 分子d组（墨绿色）
- `#E6CECF` - 备用色
- `#B696B6` - 备用色

## 使用方法

### 环境准备

1. 确保已安装Python 3.x
2. 安装依赖库：

```bash
pip3 install matplotlib numpy
```

### 运行程序

```bash
python3 plot_data.py
```

### 输出结果

程序运行后将生成两个高分辨率（300 DPI）的PNG图像文件：
1. `il6_bar_chart.png` - IL-6水平柱状图
2. `relative_line_chart.png` - 相对抑制效果曲线图

## 数据说明

### 浓度组
- 0 μM：对照组（blank + LPS）
- 2 μM：分子a, b, c, d
- 4 μM：分子a, b, c, d
- 8 μM：分子a, b, c, d
- 16 μM：分子a, b, c, d
- 32 μM：分子a, b, c, d

### 数据类型
- **IL-6水平**：单位为pg/mL，表示白细胞介素-6的绝对浓度
- **相对抑制**：单位为%，表示相对于LPS对照组的抑制效果
- **误差**：所有数据点均包含误差值，以误差棒形式展示

## 图表特性

### 柱状图特性
- 清晰的分组显示
- 每组使用不同颜色区分
- 包含误差棒
- 网格线辅助读数
- 简洁的坐标轴标签

### 曲线图特性
- 四条独立曲线
- 使用标记点和连线
- 包含误差棒
- 图例清晰标注
- Y轴范围0-110%便于观察
